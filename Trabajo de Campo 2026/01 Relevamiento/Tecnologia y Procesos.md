# Tecnología y Procesos

> Extraído de la entrevista. Relevante para la descripción del sistema elegido (punto vii).

## Plataformas de venta con el Estado

- El gobierno de Mendoza definió que casi todas las **municipalidades y dependencias** operen a través de plataformas (**COMP.AR**, **LAX**) para evitar corrupción y "amiguismo".
- Ellos ingresan al **pedido de cotización** y compiten con todas las empresas.
- Ventaja competitiva: mejor servicio, rapidez de entrega y repuestos de mejor calidad (aunque a veces ~20.000–30.000 pesos más caros).

## Sistemas y digitalización

- **Todo está digitalizado.** Los presupuestos se pasan por **WhatsApp** o plataformas y se manejan en **digital (PDF)**.
- Casi no usan papel: solo imprimen presupuestos informales por WhatsApp (para tener respaldo si el cliente borra el mensaje).
- La encargada tiene formación (estudió 3 años en la UTN) y sabe exigir a un informático para armar servidor/dominio/página web.

## Proceso del taller — clientes privados

1. Ingresa el vehículo con una **falla predeterminada** por el cliente.
2. Se ataca la **falla puntual** indicada.
3. Se revisa el **equipo en general** (otras falencias).
4. Se llama al cliente / se lo invita al taller para mostrarle el **equipo desarmado** y explicar el problema.
5. Se arma un **presupuesto detallado**.
6. **Regla de oro:** no se hace nada sin la aprobación del cliente.

## Proceso con plataformas (Estado)

1. Ingresa el vehículo con una **falla predeterminada**.
2. Se evalúan el resto de falencias y se pasa el detalle a la administración **con precios de reparaciones incluidos**.
3. Se levanta en la plataforma **qué reparaciones hacer**.
4. El cliente decide si se hace o no la reparación.
